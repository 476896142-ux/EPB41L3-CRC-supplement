# Manuscript data and code availability statement

Replace bracketed placeholders only after the public GitHub release and Zenodo archive have been created.

> The analysis code, derived result tables, figure source data, and manuscript figures supporting this study are available in the public GitHub repository https://github.com/476896142-ux/EPB41L3-CRC-supplement. The version corresponding to this article is archived at Zenodo [DOI]. Public transcriptomic and single-cell datasets were obtained from GEO (GSE196006, GSE146009, GSE110224, GSE44076, GSE20916, GSE132257, GSE132465, and GSE146771) and should be accessed from their original repositories. Large intermediate objects, third-party resources, and access credentials are not redistributed; details of data access are provided in the repository.

Do not claim that all raw data are deposited in GitHub: the current release intentionally contains scripts and derived materials, not a full mirror of upstream datasets.
